# Nexora Gaming v1.0

Community gaming prototype: authentication, player profile, random challenges, Player Card, leaderboard and basic Admin.

## Setup
1. Run `Nexora-Gaming-v1.0.sql` in the NEW Nexora Gaming Supabase SQL Editor.
2. Upload the web files to the `nexora-gaming` GitHub repository.
3. Enable GitHub Pages from the main branch/root.
4. Register your account.
5. To make your account Admin, run the final commented UPDATE statement in the SQL file after replacing the email.

Nexora Gaming is an independent community project and is not an official Garena/Free Fire website.
